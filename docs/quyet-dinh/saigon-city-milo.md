# Saigon city and Milo change monitoring

The city remains a read-only illustration of the account's imported sources and shared sandbox clock. It does not model geography, forecast traffic, move stock, alter campaigns, or execute decisions. Bitexco is a separate riverfront landmark; MegaDay Twin is a modest signed office. The river, raised arch bridge, boats and street activity are illustrative. The two-storey MegaDay office has shaded glazing, a signed entrance and a roof terrace.

Keep React 18 and plain Three.js. Animate UI 2.x requires React 19, so this change uses compatible Motion primitives and the official shadcn Base UI Sheet/Tabs source instead of changing the app's React version. Sheets contain keyboard focus on mobile; the district inspector and Milo occupy the same panel area. The existing M favicon supplies the shared brand mark.

The Blender source, packed AO atlas, original model provenance, and PixelLab job provenance live in `tools/assets/`. Only the compressed GLB and sprite images ship to browsers. The content policy permits `wasm-unsafe-eval` specifically for Meshopt and `blob:` connections for embedded glTF images; JavaScript `unsafe-eval` remains disallowed.

Milo monitoring is deterministic, session-local and in-app. The existing source/sandbox revision feed establishes a silent baseline, batches changes for one second, ignores duplicate or regressing revisions, and retains the latest 100 notices. Reconnect compares the last observed snapshot with the current one. Rewinding the sandbox resets comparison and emits a simulation notice. Diagnostics use the existing parser's bounded result, not an exhaustive audit. There are no background AI requests, automatic speech, push notifications or mutations.

“Explain” attaches a bounded change reference and fills an empty draft; an existing draft is preserved. Only Send calls the assistant. The server loads current source values from authenticated account storage and explicitly marks client-provided historical observations as unverified. A revision mismatch is reported as stale evidence. An explanation is advisory and cannot perform a decision.

Pre-merge validation evidence and its limitations are recorded in `docs/city-demo/saigon-validation.md`.

Morning/Night is a revisioned account view preference, defaulting to Morning for older documents. It changes the current scene in place: sky/fog, hemisphere and directional lighting, glass/lamp emission, water and instanced streetlight pools. It also themes the shell, native settings dialog and portaled panels. Source time and data remain unchanged. Reduced motion freezes traffic and ripples in both modes; mode changes themselves are immediate. Named glass/lamp materials are retained during GLB optimization and covered by an asset contract test.

The seven-step tutorial includes explicit river-camera and lighting actions; opening or replaying it does not change appearance automatically. Completion uses `megaday.city.tour.v3` so returning visitors can discover the new controls.

Map labels are projected DOM buttons with keyboard names, screen-edge culling and overlap suppression. They sit above buildings rather than on the water or ground. Clicking a district opens its existing inspector path; clicking a landmark moves the camera without inventing a data panel. The Explore menu retains every landmark destination when narrow screens hide labels. Camera travel follows delta time and becomes immediate under reduced motion. Landmark 81 and infill housing are original Blender constructions; 24 instanced citizens include both riverside promenades. Neighborhood/HQ/warehouse routes illustrate available observations, not live deliveries.

Milo uses a compact pixel portrait while idle and a full-body animation with a short speech bubble for important in-app updates. Review opens the existing Updates tab; dismissing or timing out returns to the avatar and retains unread updates. Notifications never open chat or call AI on their own.
